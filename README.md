# Portfolio

Source for my personal site, served by GitHub Pages.

- `index.html` is the whole page. No build step, no dependencies, no framework.
- `preview.png` is the social preview card.
- English only. The site used to carry twelve translations in `lang/`;
  keeping them in step cost more than the switcher was worth, so the
  copy now lives only in `index.html`.

Edit `index.html`, commit, push. GitHub Pages redeploys in about a minute.
